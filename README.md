# Branching Strategy
## Admin's User Management Backend
    
if you don't already have this project, clone this. Otherwise, you don't need it.
```bash
   git clone https://github.com/ACE-JWD62/pos.git
```
if you already have this project.

### Create new branch for your ticket
**Branch name must be the same as ticket name**
``` 
# 1. Start from dev
git checkout dev
git pull origin dev

# 2. Create a feature branch
git checkout -b <your ticket name>

# 3. Work, then commit changes
git add .
git commit -m "write commit message"

# 4. Push feature branch
git push origin <your ticket name>
```
